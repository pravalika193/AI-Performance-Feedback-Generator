## Project Overview

The AI Performance Feedback Generator is a web-based application that analyzes student performance and generates personalized feedback.

The system accepts student marks in different subjects and calculates the average score. Based on the performance level, it generates personalized feedback, identifies strengths, identifies areas for improvement, and provides actionable recommendations.

The system also uses Natural Language Processing for sentiment analysis of the generated feedback.

---

## Features

- Student name input
- Subject-wise marks input
- Automatic average score calculation
- Performance level classification
- Strength identification
- Areas for improvement
- Personalized feedback generation
- NLP-based sentiment analysis
- Actionable recommendations
- Feedback report download
- Web-based user interface
- Input validation

---

## Performance Levels

| Average Score | Performance |
|---|---|
| 85 - 100 | Excellent |
| 70 - 84 | Good |
| 50 - 69 | Average |
| Below 50 | Needs Improvement |
